## Product Goal

CLI tool that installs a local operating layer for coding agents to prevent scope drift

## Users / Audience

Developers using Claude Code, Codex, Cursor, or Windsurf on production codebases

## Current Architecture

Framework: None — vanilla Node.js CLI tool (no web framework)
App structure: bin/ (CLI entry), lib/ (core logic), templates/ (scaffold files), prompts/ (prompt templates), skills/ (adapter-specific skill files), test/ (Node.js built-in tests)
Package manager: npm (no lockfile — no external dependencies)

## Core Workflows

1. `agentbubble init [--force] [--yes] [--adapter <claude|cursor|codex|generic|none>]` — scaffolds .agentbubble/ in a project, detects framework/stack, generates context.md + architecture.md, writes adapter pointers (CLAUDE.md, .cursorrules, AGENTS.md)
2. `agentbubble audit` — reads current-ticket.md, gets git diff, checks changed files against scope patterns and default risk rules, outputs scope drift report
